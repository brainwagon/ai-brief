  • SWE Refactor Bench: Can Coding Agents Complete a Long-Horizon, Whole-Repository Stack Migration?

    SWE Refactor Bench is a new benchmark with 20 whole-repository migration tasks that measures whether coding agents actually perform technical debt migrations (not just pass tests), using a three-stage evaluation that separates migration completeness from behavioural correctness; results show only 5.4% of 520 agent runs pass all stages, highlighting the difficulty of reliable autonomous refactoring.

  • FixAnything: 3D-Consistent Rendering Refinement via Video Generative Priors

    FixAnything repurposes a pretrained video generative model to refine rendering artifacts across multiple 3D representations (NeRF, 3DGS, meshes, point clouds) using video-to-video translation with mask-guided structure preservation and DPO using SfM-derived pose accuracy as reward, requiring only lightweight finetuning.

  • Mitigating Reasoning-Induced Misalignment via Safety-Direction Penalty

    The paper identifies how fine-tuning on benign reasoning data can degrade safety by shifting internal safety representations, proposes a Safety-Direction Penalty that constrains this shift during training, and validates it on Qwen2.5 models to recover safety without hurting reasoning performance.

    Score 4cs.AI, cs.CL · submitted 24 Aug

  • SRPO: Self-Reflective Policy Optimization for Long-Horizon Reasoning

    SRPO is a training framework that enables LLMs to generate self-reflections on their own trajectories to create dense token-level learning signals from sparse rewards, achieving strong reasoning and agentic performance with significantly reduced compute using Qwen3-8B.

    Score 4cs.AI · submitted 24 Aug

  • GeoWAM: Visual Geometry World Action Models for Autonomous Driving

    GeoWAM is a world action model for autonomous driving that predicts future scene geometry from point clouds instead of images, using this geometric pretraining to improve ego-trajectory prediction in both open-loop and closed-loop evaluations.

    Score 4cs.CV · submitted 24 Aug

  • ProxyFormer: A Dual-Stream Proxy Architecture for Ultra-Long Context and High-Resolution Generation

    ProxyFormer introduces a dual-stream architecture using proxy tokens to compress and decompress features across layers, enabling training of ultra-long sequences (up to 0.7M tokens) on a 16GB GPU while preserving fine-grained information and achieving strong needle-in-haystack retrieval accuracy.

    Score 4cs.LG · submitted 24 Aug
