    cmHC geometrically contracts the Birkhoff polytope interior to balance residual stream mixing, preventing under-mixing (degeneration into independent streams) and over-mixing (stream indistinguishability), with fused operators reducing hyper-connection latency by up to 44.8% on Ascend NPUs.

    Score 481 upvotes · arXiv 2611.27193

  • Non-penetrating World Models

    NoPeBench evaluates six open-source video world models and finds none can prevent object penetration; NoPeWorld adds a lightweight prediction head on frozen diffusion transformers that reads hidden states to detect and replace unsafe actions, cutting violation rates from 74% to 16% and generalizing zero-shot.

    Score 451 upvotes · arXiv 2611.27963

  • Clover-35B-A3B-Preview Technical Report

    A technical report on Clover-35B-A3B-Preview, a mixture-of-experts diffusion language model with 35 billion total and 3 billion activated parameters, using Gated Delta Networks for block diffusion; it achieves 73.6 on SWE-bench Verified and 680 tokens/s on one NVIDIA GB300 GPU, and includes a decision-model variant for joint prediction that raises question accuracy from 90.37% to 93.88%.

    PickScore 434 upvotes · arXiv 2611.24636

  • Reading the Unreadable: Text-Aware Image Super-Resolution Needs Reasoning

    Introduces a benchmark (ReasonText) and metric (GTTCA) to evaluate text-aware image super-resolution, finding that models consistently fail on text requiring reasoning; proposes Reasoning Transfer via Captioning (RTC), a training-free plug-in that uses an MLLM to infer degraded text and feeds the caption to a text-conditioned SR model, improving performance across six models.

    Score 421 upvotes · arXiv 2611.15449

  • MemOnce: A Scalable Memory Architecture for Large Language Models

    MemOnce is a transformer architecture that caches only a subset of final-layer hidden states as compact memory representations and dynamically decodes them into KV caches for attention layers, reducing GPU memory footprint and achieving linear-time complexity; adapting a 4B model reduces memory state cache by 1313x and prefill latency by 6.9x at 1M context.

    PickScore 415 upvotes · arXiv 2611.27973

  • Duopra: From Full-Duplex Conversation to Full-Duplex Agency

    Duopra is a full-duplex interaction model that learns both conversational turn-taking and task execution; on Full-Duplex-Bench v3, it improves tool-calling Pass@1 from 4.7% to 44.7% via three-stage training combining SFT, reinforcement learning, and projector-only repair.

    Score 410 upvotes · arXiv 2611.25773

  • StereoVLM: Binocular Vision-Language Models for Metric 3D Spatial Reasoning

    StereoVLM introduces a binocular vision-language model that uses calibrated stereo geometry and hierarchical supervision—from disparity to metric depth—to achieve 95.17% depth accuracy and 66.98 average object-level scores on the new Stereo3D-Bench benchmark, with manipulation gains of 4.3 percentage points in RoboCasa.

    Score 46 upvotes · arXiv 2611.27915

  • AeroRSI: Recursive Self-Improvement for Aerial Vision-Language Navigation

    AeroRSI is a recursive self-improvement framework for aerial vision-language navigation where a 2B-parameter policy iteratively learns from its own failures by verifying sampled repairs when flown from the failure state, raising success rate from 46.4% to 67.5% on TravelUAV and halving collisions without extra human labels or inference cost.
