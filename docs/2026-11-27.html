  • Stable Gated DeltaNet-2: Understanding and Mitigating Recurrent State Instability

    Gated DeltaNet-2 (GDN-2) enhances linear attention with independent channel-wise control over erasure and writing, but suffers training failures due to non-normal erase operators causing exponential state growth; the proposed solution uses symmetric erasure and decay-regulated residual writing to bound state growth, improving 128K RULER score by 6.80 points and downstream task accuracy by 0.62 points on 1.6B parameter models.

    PickScore 4115 upvotes · arXiv 2611.34051

  • Entangle: Scaling Human-Video In-Context World-Action Models across Unseen Tasks and Contexts

    Entangle is an in-context world-action model for robotic manipulation that takes a single human demonstration video and current robot observations as input and predicts future visual states and executable actions, without task-specific fine-tuning. It addresses the challenge of scaling human-video in-context learning by converting recorded robot videos into matched human contexts via video-to-video generation and using an intra-task contrastive objective to prevent the model from relying on task-identity shortcuts, achieving an average score of 83.5/100 across six unseen tasks on an Astribot S1 robot.

    Score 433 upvotes · arXiv 2611.28732

  • StateWeaver: Multi-Agent Coordination of Story-State Transitions for Long-Horizon Video Generation

    StateWeaver combines Active States, which translate review-detected state discrepancies into concrete visual asset requirements, and Hierarchical Collaboration, which isolates execution contexts across tasks, clips, and repair rounds with hierarchical memory, to produce long videos with sustained cross-shot consistency under predefined or autonomously planned storyboards.

    Score 423 upvotes · arXiv 2611.34290

  • ShowNow: Fine-Grained Speculative Streaming for Responsive World Models

    ShowNow is a speculative streaming framework for interactive world models that uses computation during video playback to pre-compute action-conditioned future frames, enabling 5B-parameter 480p generation at 16 fps on a single H100 GPU and reducing median input-to-display latency from 620 ms to 208 ms in ViZDoom.

    Score 419 upvotes · arXiv 2611.34693

  • WorldBridge: Bridging Scattered Views for Coherent 3D World Generation

    A framework that generates coherent 3D worlds from scattered images with little or no visual overlap, using temporal and spatial reference attention and a plug-and-play latent-reference consistency strategy.

    Score 410 upvotes · arXiv 2611.34079

  • Boundary-Aware Policy Learning for Agent-Orchestrated Robot Manipulation

    A method for agent-orchestrated robot manipulation that explicitly shapes the 'handoff boundary'—the set of start states where a visuomotor policy is reliable—by first fine-tuning the policy on diverse contact segments and then retraining on successful rollouts, achieving 98.4% success on RoboTwin 2.0 while cutting API cost 41.3% and execution time 37.5%.

    Score 47 upvotes · arXiv 2611.32238

  • Edit Recommendation: Can LLMs Anticipate Edit Requests from Users, and When?

    Defines the task of edit recommendation—where an LLM predicts user edit requests before they are sent—and introduces EditRecBench, a benchmark built from WildChat-4.8M conversation logs, alongside a gating mechanism that filters out low-confidence predictions to improve suggestion accuracy by 12–25 points pass@5.

    Score 43 upvotes · arXiv 2611.21155

  • When Does Reasoning Help Entity Disambiguation? Small LLMs In-Domain and Under Shift

    Compares reasoning-based and reranking-based entity disambiguation in small LLMs across in-domain, few-shot, and true zero-shot settings, finding reasoning provides negligible benefit in-domain but decisive advantage under domain shift.
