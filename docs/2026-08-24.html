    SPARCL addresses forgetting in analytic continual learning by partitioning the autocorrelation matrix to freeze old class components in a core subspace and updating only a residual block with recursive least squares. This method preserves old-class accuracy while updating new classes on datasets like CIFAR-100 and ImageNet.
