  • $Z$-sight: Unifying Vision-Language-Action and Latent World Modeling

    Z-sight is a unified robot foundation model that jointly denoises future visual tokens and actions using a mixture-of-transformers combining a vision-language model with a foresight expert and a continuous action expert, achieving 81.9% success on SIMPLE and 73.3% across six Unitree G1 tasks at 110 ms per chunk without pixel reconstruction or external encoders.

    Score 4cs.RO, cs.CV · submitted 18 Nov

  • Jailbreak Detection on Large Language Models via Contrastive Prototype Structures

    Score 4cs.CL · submitted 18 Nov

  • Knowing What You Know: A Trait Theory of Reviewer Value in Human-AI Cognitive Systems

    A theory that a human reviewer's value in AI-assisted decision-making is determined by metacognitive calibration (the alignment between confidence and accuracy) rather than activity, speed, or tenure, supported by a six-month study of an accounting system with 483 reviewers and 541,621 events.

    Score 4cs.AI, cs.LG · submitted 18 Nov

  • Agentic Harness Engineering Beta: Requirement-Centered Evolution of Agent Harnesses

    AHE-Beta is a requirement-centered loop for evolving agent harnesses that uses simulated users to raise issues, team-based modification to implement generalizable changes, and requirement-driven selection to merge changes only when they resolve verified requirements; on held-out tasks it raises pass@1 from 21.9% to 33.3% while using 40.8% fewer tokens than Base Harness, and outperforms Claude Code, Meta-Harness, and AHE in a blind human A/B test.

    Score 4cs.SE, cs.AI · submitted 18 Nov

  • PrismRestore: A Compact Restoration Toolbox for Agentic Image Restoration

    A system that extracts a compact bank of restoration actions from a single frozen all-in-one model, using offline task-prior search and a state-conditioned policy trained with Group Relative Policy Optimization, matching multi-model agents on synthetic and real-world benchmarks with a single backbone and faster inference.

    Score 4cs.CV · submitted 18 Nov

  • Decomposing SGD Dynamics in Neural Networks: Teacher-Induced Spikes and Variance Inflation

    A study of two-layer neural networks trained via SGD on a multi-index teacher model, decomposing first-layer weights into teacher-aligned and orthogonal components; the orthogonal complement develops teacher-induced spectral spikes that inflate variance and degrade generalization, which the authors analyze through a proposed Decomposed Dynamics surrogate.

    Score 4stat.ML, cs.LG · submitted 18 Nov

  • Equivariant Modeling with Polynomial Features via Minimal Homogeneous Generators

    A framework for learning equivariant functions between group representations uses minimal homogeneous generators of the invariant algebra and covariant module as polynomial features, with a Python package that computes features via isotypic and Clebsch-Gordan decompositions, demonstrated in scientific modeling with few parameters.

    Score 4cs.LG, stat.ML · submitted 18 Nov

  • Cap-and-Track: Optimizing LLM Inference Request Dispatch Across Shifting Capacity

    Cap-and-Track is a dispatch design for LLM inference that uses fail-fast admission refusals from saturated backends to probe and adjust dispatch rates without needing output-length prediction or fleet-level rate tuning. Meta's traffic shaper implemented it for post and live-video understanding, serving 300 million requests daily and running a classifier on 43% fewer H100s than its fixed-rate precursor in a production A/B test.

    Score 4cs.LG · submitted 18 Nov

  • Jeveration: System One Models Now Generate

    Jeveration is a System One model that generates 512x512 images in a single forward pass (78 ms, up to 122× faster than prior unified models) by conditioning parallel predictions on a shared random state for global coherence.     PickScore 454 upvotes · arXiv 2611.24738

  • The Resolution Hypothesis: Agent Evolution's Key Is Identifying Improvements

    Analyzes the Resolution Hypothesis, which claims agent evolution fails not because systems can't propose better artifacts (prompts, skills, memories) but because noisy evaluations prevent reliably identifying improvements. Tests across seven evolution methods and six models (over 10M LLM calls), finding selection of candidates is no better than random and published method rankings often reflect luck rather than real differences.

    PickScore 428 upvotes · arXiv 2611.23068

  • PROLA: Principal-Orthogonal Low-rank Adaptation for Predictive Spatiotemporal Weather Downscaling

    A weather downscaling framework that decomposes prediction into spatial and temporal stages using a shared pretrained backbone, fixed numerical scaffolds, and lightweight residual heads, with PROLA being a low-rank adaptation method that allocates a fixed budget between principal directions and orthogonal complements and rescales optimizer updates via gradient signals to improve backbone adaptation.

    Score 427 upvotes · arXiv 2611.11318

  • ALIVE: Making Streaming Video Models Interactive

  • HINT-WAM: Hindsight-Informed Training for World Action Models

  • CurvDelta: Low-Curvature Delta Modeling For Surgical Learning and Unlearning
