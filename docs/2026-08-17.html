  • Split the Labor: Separating Evidence Interpretation from Decision Aggregation

    This work separates evidence interpretation from decision aggregation using a structured evidence tuple (hypothesis, reliability bucket, rationale, provenance) and proposes using pooled calibrated log-likelihood ratios to combine these interpretations, demonstrating a method applicable beyond LLMs to score-summing triage engines.

    Score 4cs.AI, cs.CL · submitted 14 Aug

  • Rollplex: Cross-Phase GPU Spatial Sharing for Vision Language Model Post-Training

    Rollplex is a runtime for Vision-Language Models that optimizes on-policy Reinforcement Learning by overlapping the processing of video prefixes with the rollout decoding phase, achieving significant speedups via phase-aware memory management and parallelism-aware weight sharing.

    PickScore 4cs.LG · submitted 14 Aug

  • Approximate Muon with low-rank adapters

    This work adapts the Muon optimizer for parameter-efficient fine-tuning (PEFT) by approximating its objective in the low-rank setting using linearization and least-squares, resulting in an efficient method named sMuon.

    Score 4cs.LG · submitted 14 Aug

  • Twin: Playing an Unknown Game with a Test-Time Digital Twin

    Twin is a test-time world-model inference system where an agent writes an executable world model to solve unknown grid games by simulating interactions and using observed transitions to repair the model until successful play is achieved.

    PickScore 4cs.AI · submitted 14 Aug

  • You Only Pass Once: Answering and Abstaining Together in a Single Forward Pass of a Frozen Language Model

    This work introduces YOPO, a method that allows a frozen language model to answer, actively steer its internal representation, and abstain from answering in a single forward pass, significantly boosting accuracy over previous multi-pass methods.

    Score 4cs.CL, cs.LG · submitted 14 Aug
