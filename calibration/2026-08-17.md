trailing whitespace, replaces the literal string `{{RUBRIC}}` in `prompt.md`, and
the result is sent verbatim as the system message. Nothing else in either file is
transformed.

## What this means for the size of an Edition

The right-hand column above is the honest ceiling arithmetic on the candidate
pool: **42 Items**, above map note 6's 15–25. It is an overestimate, because the
Snapshot diff had not been applied. On a real Run the four Snapshot Sources
contribute only their *new entrants* — measured on #10 and #4 at roughly 6/day for
GitHub New Repos and a similar handful for the two Hugging Face trending lists —
and arXiv contributes nothing at all on a Run whose 96-hour window holds only
already-published papers. Carrying those through the same Scores gives a typical
Edition of roughly **20–28 Items**, and a quiet-day Edition well under that.

That is close enough to the target that the cutoff stays at 3. If real Editions
come in persistently fat, the lever is this file — tighten the 3 — and not the
cutoff, because Score ≥3 is the only number the page's meaning depends on.

## The floor, when a Source has fewer than 3 qualifying Items

Map note 6's floor of 3 per Source is a **cap that yields, not a quota that
lowers the cutoff.** #4 proved the floor is unreachable in the ordinary course —
HF Papers returns an empty array every Sunday, arXiv's window is empty on most
Runs — and this calibration adds two more: Hacker News and dev.to each cleared
the cutoff with 2 Items on a perfectly normal Monday.

Precisely:

1. **The cutoff never moves.** Score ≥3 is absolute and is never relaxed to fill a
   quota. A Source with 0, 1, or 2 qualifying Items contributes exactly that many.
   A padded Item is indistinguishable on the page from an earned one, which would
   destroy the only thing a Score means.
2. **A Source's floor is `min(3, qualifying Items)`.** The floor's real work is
   protecting breadth when the day is *full*: if the day must be trimmed toward
   the 15–25 target, trimming goes by Score ascending across the whole Edition,
   but no Source is trimmed below 3 Items while any other Source still holds more
   than 3. The ceiling of 8 is unchanged and remains a hard cap.
3. **A Source that qualifies nothing is not Unavailable.** It answered; it had
   nothing to show. Per #4 that distinction is load-bearing, and per #6 such a
   Source stays plain grey on the page while an Unavailable one is ochre and
   dashed.

### HF Papers

- **4** — Marionette: Predicting World States, Rendering Geometry, Painting Appearance  
  Marionette is a world model for interactive games that predicts an explicit, 3D, multi-entity state (skeletons, trajectories, rotations) and uses a zero-parameter renderer to compute geometry before a video-diffusion model synthesizes the final photorealistic appearance from the structured control.
- **4** — Second Thought: Reasoning in Parallel as LLM Agents Act and Observe  
  Second Thought is a training-free inference framework for LLM agents that concurrently runs four auxiliary reasoning branches during the action/observation idle window, merging the results back to the main loop to improve agent performance while reducing main thread decoding time.
- **4** — SimpleOPD: Simple Tokenizer-Agnostic On-Policy Distillation for Long-Context Reasoning  
  SimpleOPD is a distillation technique that transfers reasoning capabilities from long-context teacher models to short-context student models by operating in a shared text space and aligning tokens based on identical text spans, while also introducing a student reference KL loss to manage excessive output length.
- **4** — Dion3: Full-Stack Orthogonal Updates  
  Dion3 is a revised optimizer building on Muon that reduces the computational overhead of orthogonalization via a Gram Newton-Schulz algorithm, accelerated kernels, and a modified update rule, achieving significant speedups while maintaining or improving performance.
- **4** — UNMASK: Discovering and Causally Verifying Spurious Shortcuts in Text Classifiers  
  UNMASK is an automated pipeline that discovers and causally verifies spurious surface patterns in text classifiers by generating executable boolean expressions from unlabeled examples and validating them via counterfactual interventions.
- **3** — Intern-S2-Mobius: Foundation Model with Decoupled Knowledge and Reasoning  
  Mobius-v0 is a model architecture that decouples knowledge into a shared Memory (FFN) and separates reasoning into multiple Reasoners (Self-Attn) to improve knowledge compression and reasoning efficiency.
- **3** — MobileMem: Learning from a Year of Mobile Experiences  
  MobileMem is a benchmark and framework for testing on-device, long-term memory for AI agents, built from a year's worth of diverse, multimodal mobile user experiences to test temporal reasoning and knowledge updating.
- **3** — HumanTracker: Towards Comprehensive and Human-Aligned Motion Tracking Benchmark  
  HumanTracker is a comprehensive motion tracking benchmark using 153 hours of humanoid trajectories to evaluate motion by diagnosing physical artifacts like foot skating, alongside a new metric called HumanScore trained on human preference data.
- **3** — Self-Supervised Visual On-Policy Distillation  
  Self-Supervised Visual On-Policy Distillation (S^2VOPD) constructs on-policy learning signals by creating an information asymmetry between the teacher's distribution (conditioned on the original image) and the student's distribution (conditioned on a strongly augmented view) to achieve performance gains without ground-truth data or a separate teacher model.
- **3** — Claim-Level Reliability Assessment for Efficient Test-Time Reasoning  
  This paper introduces Claim-Level Reliability Assessment (CLR), a training-free framework that analyzes reasoning traces by condensing them into decision-critical claims to test for falsification, showing improvements over standard self-consistency checks with fewer tokens.
- **3** — Forecast Collapse in Time-Series Foundation Models  
  The paper introduces forecast collapse, where time-series foundation models predict flat returns for many assets, and proposes a new objective function, CalibRank, to balance prediction calibration with cross-sectional ranking correlation.
- **3** — PRM-as-a-Judge 1.5: A Toolkit for Robot Process Assessment  
  PRM-as-a-Judge 1.5 is a toolkit that processes robot rollout videos to derive fine-grained metrics for assessing embodied models, including metrics for failure-side progress and recovery.
- **3** — Latent On-Policy Self-Distillation  
  Latent On-Policy Self-Distillation (LOPD) is a method that makes the source of supervision for self-training end-to-end learnable by retrieving and composing relevant experiences into continuous latent tokens to condition a self-teacher.
- **3** — Scaling Domain Data Repetition in LLM Pretraining  
  This work investigates how to optimally repeat limited, high-quality domain data to counteract data dilution when training very large language models, suggesting that the optimal repetition count can be estimated using smaller proxy models.
- **3** — Multimodal Model Diffing for Feature Discovery and Control  
  MMDiff is a framework that trains multimodal Sparse Autoencoders (SAEs) to create feature-level interfaces for discovering and controlling behaviors within Multimodal LLMs (MLLMs). It allows users to identify features altered by multimodal training, detect causal features per-token, and steer or remove these features for targeted control.
- **3** — Verifier-Induced Support Reshaping in On-Policy Optimization  
  This work introduces Verifier-Induced Support Reshaping (RLVR) in on-policy RL, showing that optimizing for a current objective can deplete the sample support for future, related objectives, which is demonstrated across mathematical reasoning and instruction following tasks.
- **3** — LittleLearner: Language Models Under Pedagogically Controlled Knowledge Exposure  
  LITTLELEARNER is a 5B-parameter language model trained on LITTLECURRICULUM, a curated 88B-token corpus of U.S. elementary school material that explicitly excludes knowledge above Grade 5, creating a controlled sandbox for studying knowledge acquisition.
- **3** — UniProbe: A Learnable Token-Level Hallucination Detector for Large VLMs using Multi-Structural Internal Representations  
  UniProbe is a lightweight, unified detector that builds a directed graph over image patches, query tokens, and generated tokens within a VLM's forward pass, using interleaved GNN, ViT, and GRU modules to detect token-level hallucinations.
- **3** — SPARGen: Unifying Spatial Perception and Reasoning through Native Multimodal Generation  
  SPARGen is a unified multimodal framework that treats 3D reconstruction, dense correspondence, and spatial reasoning as instruction-conditioned generation tasks, outputting structured and geometric fields as token sequences.
- **3** — Generation as Auxiliary Supervision: Enhancing Visual Understanding at Zero Inference Overhead via Decoupled Embedding Prediction  
  The GAS framework treats visual generation as an auxiliary supervision signal for representation learning by adapting Next Embedding Prediction within a decoupled Mixture-of-Transformers architecture to enhance visual understanding without adding inference overhead.
- **2** — Can We Defend Against AI-Generated Video Attacks on Real-World Crisis Events? A Systematic Evaluation of Detectors, Generators and Social Dissemination  
  The paper introduces RA-Bench, a benchmark dataset of 17,886 videos mixing real and AI-generated clips across ten social-risk categories to systematically evaluate the generalization capabilities of current video detection methods.
- **2** — Beyond Final Scores: A Systematic Evaluation of Agents for Long-Horizon AI Research and Development  
  This work systematically evaluates seven frontier AI agents across 36 long-horizon tasks using a new framework to measure in-run behavior, finding that current agents act more like engineering optimizers than truly autonomous researchers.
- **2** — CPI-Bench: A Comprehensive,Practical and Intelligent Benchmark for Real-World Image Editing  
  CPI-Bench is a proposed benchmark designed to evaluate real-world image editing by covering three subsets: general tasks, high-frequency practical scenarios, and highly demanding reasoning-based editing.
